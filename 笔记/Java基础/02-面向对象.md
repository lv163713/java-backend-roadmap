## 三、继承

### 核心要点
- `extends` 单继承；所有类隐式继承 `Object`
- 构造器链：子类构造器第一行默认 `super()`；`this()` 与 `super()` 不能同时出现
- 方法重写（`@Override`）规则：方法名/参数列表相同、返回值协变、访问权限不能缩小、异常不能变宽
- `super` 调用父类成员
- `Object` 类常用方法：`toString()` / `equals()` / `hashCode()` / `getClass()` / `clone()` / `finalize()`
- `final` 修饰类（不可继承）/ 方法（不可重写）/ 变量（常量）
- 初始化顺序：父类静态 → 子类静态 → 父类成员/代码块/构造 → 子类成员/代码块/构造

## 五、重载（Overload）与重写（Override）

| 对比项 | 重载 Overload | 重写 Override |
|:---|:---|:---|
| 发生位置 | 同一个类 | 子类重写父类 |
| 方法名 | 相同 | 相同 |
| 参数列表 | **必须不同** | 必须相同 |
| 返回值 | 无关 | 协变（子类类型或更小） |
| 访问修饰符 | 无关 | 不能更严格 |
| 异常 | 无关 | 不能抛出更宽泛的检查异常 |
| 绑定时机 | 编译期（静态） | 运行期（动态） |

## 七、抽象类（abstract）

### 核心要点
- 抽象类不能实例化；可以有构造器（供子类 super 调用）
- 抽象方法没有方法体；含抽象方法的类必须是抽象类
- 子类必须实现所有抽象方法，否则子类也得是抽象类
- `abstract` 与 `final` / `private` / `static` 不能共存（原因：矛盾）

## 八、接口（interface）

### 核心要点
- 接口中的成员：常量（`public static final`）、抽象方法、`default` 方法、`static` 方法、`private` 方法（JDK9+）
- 一个类可 `implements` 多个接口；接口可 `extends` 多个接口
- 与抽象类的区别（**面试必问**）：

| 对比项 | 抽象类 | 接口 |
|:---|:---|:---|
| 关键字 | abstract class | interface |
| 继承数量 | 单继承 | 多实现 |
| 成员变量 | 任意 | 只能是 public static final |
| 方法 | 可有具体实现 | JDK8 前只能抽象，现可 default/static |
| 构造器 | 有 | 无 |
| 设计意义 | is-a（模板复用） | has-a / can-do（行为契约） |

- `default` 方法冲突解决：必须重写
- 函数式接口 `@FunctionalInterface`

## 十一、泛型

### 核心要点
- 泛型类 / 泛型方法 / 泛型接口
- 通配符：`?` / `? extends T`（上界，只能取）/ `? super T`（下界，只能存）—— **PECS 原则**
- **类型擦除**：编译后泛型信息被擦除，`List<String>` 与 `List<Integer>` 运行时类相同
- 擦除带来的限制：不能 `new T()`、不能 `new T[]`、不能对泛型做 `instanceof`、静态方法不能用类的泛型参数
- 为什么引入泛型：类型安全 + 消除强制转换
