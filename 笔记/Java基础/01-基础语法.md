## 四、运算符

### 核心要点
- 算术：`+ - * / % ++ --`（`++` 前置与后置的区别：`i = i++` 结果是？）

- 三元：`条件 ? 值1 : 值2`
- 优先级：`()` > 单目 > 算术 > 移位 > 关系 > 位 > 逻辑 > 三元 > 赋值

## 六、数组

### 核心要点
- 声明与初始化三种方式：`int[] a = new int[5];`、`int[] a = {1,2,3};`、`int[] a = new int[]{1,2,3};`
- 默认值：整型 0、浮点 0.0、char `\u0000`、boolean false、引用 null
- 内存结构：数组变量在栈，数组对象在堆，`length` 是属性不是方法
- `ArrayIndexOutOfBoundsException`、`NullPointerException`
- `Arrays` 工具类：`sort` / `toString` / `binarySearch` / `copyOf` / `equals` / `fill`
- 二维数组：`int[][] a = new int[3][4];`，本质是数组的数组
- 可变参数：`void f(int... nums)`
